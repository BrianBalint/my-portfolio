Projects

Meridian CRM Platform

A full-stack SaaS CRM built to be customized to any organization rather than locked to one vertical. React and TypeScript front end, Flask and Gunicorn API, PostgreSQL behind it, served by nginx. Deployed either on infrastructure the customer already owns or hosted for them.

React TypeScript Flask PostgreSQL

Meridian Backup

A backup and disaster recovery platform built from scratch to replace Veeam at client sites, aiming at what a Datto appliance does without the appliance. Agents protect Hyper-V virtual machines and file data and reach outward to a central repository, so a recovery means standing a protected system back up rather than unpacking an archive and hoping. Agent and server are .NET 8, with deduplicating content-addressed storage underneath and the backup orchestration written on top of it.

C# .NET 8 Hyper-V restic

Swift Support

A remote support platform built to replace hosted tools like GoToAssist. The agent installs from an MSI and dials outward to a relay, and the technician works from a browser portal, so no inbound firewall rule is ever needed on the client side. Supports both attended and unattended sessions.

Windows agent MSI WebSockets Relay architecture

TDS Mailer

A custom email campaign platform built from scratch to replace an off-the-shelf tool. Contenteditable campaign and template editors, image upload, open and click tracking, contact import with upsert, and a campaign scheduler. Later rebuilt as a React single-page app against the same API.

Flask PostgreSQL React Postfix

StrategiX Global

A marketing site and a separate operations platform for a conference and event management firm. The platform books travel through a GDS and manages events end to end, covering vendors, resources and attendees, with a global calendar spanning every traveler.

React Vite nginx GDS integration

Multi-Site Backup Infrastructure

Hyper-V replication across three sites over certificate-authenticated WireGuard tunnels, with PowerShell handling monthly full and daily incremental disk backups, retention policy and email alerting. One site carries a seven-year retention requirement for regulatory compliance, which drove a roughly fifty terabyte lifecycle plan.

Hyper-V WireGuard PowerShell Veeam

VHD Builder

An enterprise backup platform that produces bootable virtual disks from protected systems, so a recovery is a machine you can start rather than an archive you have to restore first. A C# Windows application using VSS with incremental and differential chains, packaged as an MSI, paired with a Linux backup server and a licensing system using hardware fingerprinting.

C# VSS WiX Flask
